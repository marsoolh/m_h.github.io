# Editing Reference

## index.html references

- `HEADER / NAVIGATION`: top tabs
- `RIGHT SIDE SOCIAL BAR`: LinkedIn, Email, Resume, Medium links
- `HERO SECTION`: main headline and summary
- `ABOUT SECTION`: professional positioning
- `JOURNEY SECTION`: timeline, newest first
- `EXPERIENCE SECTION`: detailed work history
- `IMPACT / PROJECTS SECTION`: measurable achievements
- `SKILLS SECTION`: skill groups
- `CERTIFICATIONS SECTION`: Credly links
- `EDUCATION SECTION`: academic background
- `CONTACT SECTION`: bottom call-to-action
- `RESUME MODAL`: popup message
